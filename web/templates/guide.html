Обзор системы

Система управления отелем Spasskaya включает в себя:

  • Telegram бот для гостей отеля
  • Веб-панель администратора для управления обращениями
  • QR коды для быстрого доступа к боту из номеров
  • Систему уведомлений в Telegram для персонала
Совет: Используйте горячие клавиши и фильтры для быстрой навигации по системе.

Dashboard

Главная страница

На главной странице отображается:

  • Статистика обращений по статусам (новые, в работе, выполненные, отклоненные)
  • Последние обращения (10 самых свежих)
  • Быстрые действия для перехода к фильтрам

Кликните на карточку со статистикой, чтобы перейти к отфильтрованному списку обращений.

Работа с обращениями

Список обращений

На странице обращений вы можете:

  • Просматривать все обращения от гостей
  • Фильтровать по статусу, номеру комнаты, типу обращения
  • Искать по тексту или имени пользователя
  • Быстро изменять статус обращения

Детали обращения

Кликните на обращение для просмотра деталей:

  • Информация о госте: номер комнаты, username, время обращения
  • История переписки с гостем
  • Быстрые действия: изменение статуса, ответ гостю
  • Шаблоны ответов для типовых ситуаций
Важно: После изменения статуса гость автоматически получает уведомление в Telegram.

Управление номерами

Добавление номеров

Вы можете добавлять номера двумя способами:

  1. Одиночное добавление: введите номер комнаты (например: 101)
  2. Массовое добавление: используйте диапазон (например: 201-240)

При массовом добавлении система автоматически создаст все номера в указанном диапазоне.

Удаление номеров

Для удаления номера нажмите кнопку "Удалить" рядом с нужным номером. Система попросит подтверждение.

Совет: Добавьте описание к номеру для дополнительной информации (например, тип номера или этаж).

QR коды

Генерация QR кодов

QR коды позволяют гостям быстро начать работу с ботом, просто отсканировав код в номере.

Создание отдельного QR кода:
  1. Перейдите на страницу "Номера"
  2. Нажмите кнопку "QR" рядом с нужным номером
  3. QR код сгенерируется автоматически
  4. Нажмите "Скачать PNG" для сохранения
Массовая загрузка QR кодов:
  1. На странице "Номера" нажмите кнопку "Скачать все QR коды"
  2. Система сгенерирует ZIP архив со всеми QR кодами
  3. Архив автоматически загрузится на ваш компьютер
Настройка текста на QR коде:

В разделе "Настройки" найдите параметр qr_code_text:

  • Введите желаемый текст
  • Используйте {room_number} для автоматической подстановки номера комнаты
  • Пример: "Бот поддержки номера {room_number}"
Готово: QR коды содержат прямую ссылку на бота с автоматическим вводом номера комнаты.

Система уведомлений

Настройка получателей

Добавьте сотрудников, которые должны получать уведомления о новых обращениях:

  1. Перейдите в раздел "Уведомления"
  2. Нажмите "Добавить получателя"
  3. Введите Telegram Chat ID сотрудника
  4. Опционально укажите username для удобства
Как узнать Chat ID?

Попросите сотрудника:

  1. Написать боту @userinfobot
  2. Скопировать полученный ID
  3. Передать вам этот ID
Управление получателями:
  • Активация/Деактивация: Переключайте статус получателя без удаления
  • Удаление: Полностью удалите получателя из системы
Примечание: Уведомления отправляются только активным получателям при создании нового обращения.

Шаблоны сообщений

Редактирование текстов

В разделе "Сообщения" вы можете настроить все тексты, которые использует бот:

  • Приветственное сообщение при запуске бота
  • Тексты кнопок и меню
  • Уведомления о статусах
  • Системные сообщения
Плейсхолдеры:

В шаблонах можно использовать специальные плейсхолдеры:

  • {room} - номер комнаты
  • {room_number} - номер комнаты
  • {appeal_id} - ID обращения
Сохранение изменений:
  • Одиночное сохранение: кнопка "Сохранить" рядом с каждым шаблоном
  • Массовое сохранение: кнопка "Сохранить все изменения" вверху страницы
Внимание: Изменения вступают в силу сразу после сохранения.

Настройки системы

Основные параметры
Timezone (Часовой пояс):

Выберите часовой пояс для корректного отображения времени во всей системе. Доступны основные часовые пояса России.

Admin Panel URL:

URL админ-панели используется в уведомлениях для быстрого перехода к обращениям. Убедитесь, что указан правильный адрес.

QR Code Text:

Текст, который отображается под QR кодом. Используйте {room_number} для подстановки номера комнаты.

Автосохранение: Все изменения сохраняются сразу после нажатия кнопки "Сохранить".

Аналитика

Статистика и отчеты

В разделе "Аналитика" доступна детальная статистика:

  • Обращения по статусам (круговая диаграмма)
  • Динамика обращений по дням (линейный график)
  • Топ номеров по количеству обращений
  • Типы обращений (гистограмма)
Фильтрация данных:

Используйте фильтры для анализа данных за конкретный период или по определенным критериям.

Совет: Регулярно проверяйте аналитику для выявления проблемных номеров или частых типов обращений.

Полезные советы

Быстрые действия
  • Используйте фильтры на странице обращений
  • Кликайте на статистику для перехода к отфильтрованным данным
  • Используйте шаблоны ответов для типовых ситуаций
Работа с гостями
  • Отвечайте на обращения в течение 15 минут
  • Используйте персонализированные ответы
  • Всегда меняйте статус после выполнения
Безопасность
  • Не сообщайте пароль от панели третьим лицам
  • Выходите из системы после завершения работы
  • Регулярно проверяйте список получателей уведомлений
Техническое обслуживание
  • Периодически проверяйте настройки системы
  • Обновляйте тексты сообщений при необходимости
  • Следите за актуальностью списка номеров
